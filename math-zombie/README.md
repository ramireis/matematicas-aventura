# Matemáticas vs. Zombis — Octavo EGB

Juego original de estrategia educativa para Android y Windows. El estudiante resuelve retos de Matemática para generar energía, colocar defensas y recuperar cinco sectores de Riobamba.

Incluye números enteros y racionales, potencias, raíces, notación científica, álgebra, ecuaciones, proporcionalidad, porcentajes, geometría, volumen, estadística y probabilidad.

La compilación automática produce Matematicas_vs_Zombis_Android.apk y Matematicas_vs_Zombis_Windows_Portable.zip.
