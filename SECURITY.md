# Política de seguridad

## Información sensible

No publiques tokens, contraseñas, certificados de firma, claves API, datos personales ni trabajos identificables de estudiantes.

## Reporte de problemas

Los fallos funcionales pueden registrarse mediante un issue sin incluir información sensible. Si el problema expone credenciales o datos personales, no lo publiques: revoca primero la credencial afectada y utiliza un canal privado del propietario del repositorio.

## Versiones

Mientras el proyecto se encuentre en desarrollo inicial, las correcciones se aplicarán sobre la rama `main`.
