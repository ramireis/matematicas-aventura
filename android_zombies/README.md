# Matemáticas vs. Zombis — Android

Aplicación educativa para 7.º y 8.º EGB. El juego completo está incorporado en
el APK y funciona sin Internet. La aplicación también declara acceso a Internet
para futuras ayudas, contenidos o reportes en línea; la ausencia de conexión no
bloquea ninguna misión.

## Compilación

```bash
gradle :app:assembleDebug
```

El APK se genera en `app/build/outputs/apk/debug/app-debug.apk`.
