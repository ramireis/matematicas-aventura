# Matemáticas Aventura

Proyecto educativo de matemáticas orientado a niñas y niños, diseñado para ofrecer actividades interactivas y recursos imprimibles.

## Objetivos

- Favorecer el aprendizaje mediante actividades lúdicas.
- Permitir el uso con y sin conexión cuando la aplicación esté implementada.
- Mantener versiones compatibles con Windows y Android.
- Incluir apoyo visual, retroalimentación pedagógica y material imprimible.

## Estado del proyecto

Repositorio inicializado. El código fuente y los recursos del programa deben incorporarse antes de generar instaladores `.exe` o `.apk`.

## Estructura prevista

- `src/`: código fuente compartido.
- `platforms/windows/`: configuración para Windows.
- `platforms/android/`: configuración para Android.
- `assets/`: imágenes, sonidos y recursos educativos.
- `worksheets/`: hojas de trabajo imprimibles.
- `docs/`: documentación del proyecto.
- `.github/`: plantillas y automatizaciones de GitHub.

## Seguridad

No se deben subir contraseñas, claves privadas, tokens, certificados de firma ni datos personales de estudiantes.
