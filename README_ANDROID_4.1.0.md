# Matemáticas vs. Zombis · Estudiante Android 4.1.0

Aplicación Android sin conexión para estudiantes de 2.º, 3.º, 7.º y 8.º EGB.

- Pantalla completa horizontal y controles táctiles.
- Progreso individual guardado en el dispositivo.
- Siete mundos, evaluación por isla y recursos gráficos internos.
- Sin panel, reportes ni credenciales docentes.
- Compatible con Android 6.0 o superior.
